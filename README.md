Fly Swat — simple web mini-game

Files added:
- index.html: game UI + canvas
- style.css: simple styling
- script.js: game logic (spawning flies, pointer input, scoring, game over)
- README.md: instructions and notes

How to run:
1. Open index.html in a web browser (desktop or mobile). No build step required.
2. Press Start, then tap/click flies to "swat" them. If 5 flies escape off-screen, the game ends.

Notes / ideas to extend:
- Add sound effects when a fly is swatted or escapes.
- Replace drawn flies with sprite images and add animations.
- Add levels, lives, timers, or power-ups.
